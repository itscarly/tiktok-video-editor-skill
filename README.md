# TikTok Video Editor Skill

A reusable Codex skill for turning user-provided clips into polished, privacy-conscious, upload-ready TikTok edits.

It covers clip review, story pacing, 9:16 framing, music selection, restrained on-screen captions, metadata suggestions, and final export validation.

## Use

Install or copy this skill into your Codex skills directory, then ask Codex to create or refine a TikTok video from your footage.

The skill does not publish to TikTok without explicit approval.
